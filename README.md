# 비바로체 마케팅 제작기

비바로체 제품별 마케팅 콘텐츠를 빠르게 만드는 모바일·태블릿용 도구입니다.

## 첫 등록 제품

- VA2502 클래식 컴포트 스니커즈
- 천연 소가죽 수제화
- 판매가 286,000원
- 색상: 화이트, 블랙, 블루, 핑크, 그레이
- 핵심 메시지: 깔끔한 배색과 압력 분산 구조를 더한 데일리 감각

## 제공 기능

- 광고 이미지 및 영상 프롬프트
- 카드뉴스 5장 문구
- 30초 쇼츠 대본
- 유튜브 쇼츠·틱톡·인스타 릴스용 3종 문구
- 타깃과 색상별 문구 변환
- 결과 전체 복사

## 사용 방법

브라우저에서 `index.html`을 열고 타깃, 색상, 콘텐츠 종류를 선택합니다.

> 마케팅 문구는 질병 치료나 통증 개선을 단정하지 않고 제품 구조와 착화감을 중심으로 작성합니다.
